# 服务器浏览器与筛选系统

## 项目描述

服务器浏览器与筛选系统的bug修复项目。核心模块 `network/server_browser.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 列表刷新只请求一次失败不重试无超时无分页
- 筛选条件完全没用不支持多条件组合和排序
- ping检测只发一个包不取平均值不更新
- 收藏服务器不持久化无分组无备注
- 服务器信息显示不完整不更新无详细页面

## 运行测试

```bash
python -m pytest tests/test_server_browser.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
